## Согласование с паспортом

Три исходных бизнес-вопроса в `pz2/passport.md`:

1. Выручка по регионам за январь 2024 года → Q1, slice.
2. Категории с наибольшей выручкой за весь период → Q3, dice (регион × категория), и Q4, окно (итог категории, доля и ранг).
3. Изменение выручки по месяцам 2024 года → Q2, roll-up.

Дополнительно Q2b показывает roll-up до года и Q5 показывает топ-5 магазинов.

**Важно:** замените раздел 7 файла `pz2/passport.md` содержимым `sql/passport_metric_section.md`, чтобы текст эталонного SQL совпадал точно. Для DuckDB — `FROM fact_sales`; в ClickHouse позже используется `FROM retail_dw.fact_sales`. Формула метрики одинакова.

## Разъяснение grain

Одна строка `fact_sales` — одна позиция продажи товара в магазине на дату. `COUNT(*)` считает позиции, **не количество чеков** (нет `receipt_id`) и не количество товаров (`SUM(qty)`).
