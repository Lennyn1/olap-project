## Grain

Одна строка `fact_sales` = одна зарегистрированная позиция продажи одного товара в одном магазине на одну дату, с количеством (`qty`) и суммой (`amount`). Номера чека в сырье нет.

## Состав работы

- `sql/ddl_duckdb.sql` — явные таблицы факта и трёх измерений, `DECIMAL(12,2)` для денег, ключи PK/FK.
- `scripts/load_duckdb.py` — воспроизводимая загрузка из `Стенд/data/raw/` (папка `Стенд` осталась под прежним именем, как в З01).
- `sql/checks_duckdb.sql` — ручные проверки числа строк, главной меры, пустых ключей и осиротевших FK.
- `checks/results.md` — фактические результаты, создаются после запуска скрипта.
- `retail_local.duckdb` — локальная база, создаётся после запуска, в Git не добавляется.

## Запуск на Windows 10

Откройте PowerShell в корневой папке проекта (`E:\OLAP`):

```powershell
cd E:\OLAP
py -3.11 -m pip install duckdb
py -3.11 pz3/scripts/load_duckdb.py
```

Скрипт загрузит четыре CSV-файла из `E:\OLAP\Стенд\data\raw\`. Запускать можно повторно: в транзакции сначала выполняется `DELETE`, затем `INSERT`, поэтому строки не дублируются. При ошибке транзакция откатывается.

Проверка после запуска:

```powershell
Get-Content pz3/checks/results.md
```

Если нужен интерактивный запуск SQL-проверок, можно использовать DuckDB CLI или Python. Для запуска всех проверок из PowerShell через Python:

```powershell
py -3.11 -c "import duckdb; c=duckdb.connect('pz3/retail_local.duckdb'); print(c.execute('SELECT COUNT(*), SUM(amount) FROM fact_sales').fetchall()); c.close()"
```
