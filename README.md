## Цель работы

Развернуть учебный аналитический стенд с ClickHouse и Metabase в Docker, проверить работу DuckDB и подготовить исходные данные для дальнейшего OLAP-анализа.

## Запуск стенда

Для запуска необходимо установить Docker Desktop, открыть терминал в папке `Стенд` и выполнить:

```powershell
docker compose -p olap up -d
```

Для первоначальной загрузки учебной базы данных выполнить через Git Bash:

```bash
bash scripts/init_ch.sh
```

## Используемые порты

| Сервис | Порт |
|---|---|
| ClickHouse HTTP | 8123 |
| ClickHouse Native | 9000 |
| Metabase | 3000 |

## Проверка ClickHouse

Команда:

```powershell
curl.exe http://localhost:8123/ping
```

Результат:

```text
Ok.
```

Проверка количества записей:

```sql
SELECT count()
FROM retail_dw.fact_sales;
```

Результат: **15 записей**.

## Проверка DuckDB

Команда:

```powershell
py -3.11 scripts/duckdb_smoke.py
```

## Исходные данные

Исходные файлы размещены в `Стенд/data/raw/`.

1. `dim_date.csv` — календарное измерение: date_id, full_date, year, month, month_name, day_of_week. Содержит 8 записей.
2. `dim_product.csv` — товары: product_id, product_name, category, brand. Содержит 8 записей.
3. `dim_store.csv` — магазины: store_id, store_name, city, region. Содержит 5 записей.
4. `fact_sales.csv` — факты продаж: sale_id, date_id, store_id, product_id, qty, amount. Содержит 15 записей.

Используется учебный CSV-набор из материалов курса.
