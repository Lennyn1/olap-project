# Ручные шаги и ограничения чистого стенда

1. Войти в Metabase и установить ClickHouse-драйвер для `metabase/metabase:v0.52.16` (файл jar не хранится в Git). Без драйвера пункт ClickHouse отсутствует в списке баз.
2. Обеспечить сетевого пользователя ClickHouse с SELECT на `retail_pz7.*`. Логин Metabase/email не является пользователем ClickHouse. Пароли не публиковать.
3. При новом пустом томе Metabase создать подключение к ClickHouse (`clickhouse` в сети compose либо фактическое имя контейнера, HTTP 8123, БД `retail_pz7`), четыре Native SQL-вопроса из `pz10/dashboards/`, дашборд и общий Field Filter даты. Проверить фильтр на карточках.
4. Снять два значения карточки из З11 при точно совпадающих фильтрах; передать их скрипту З11. Протокол `pz11/checks/results.md` должен говорить PASS, а не «ожидается».
5. Для переноса настроенного интерфейса сохранять Metabase app DB/том отдельно по принятым правилам бэкапа, но локальную БД Metabase и секреты **не коммитить**. Полностью автоматическое восстановление UI в данной курсовой сборке не реализовано.
6. Если уже есть рабочая система, сначала выполните только `pz12/scripts/check_contour.py`: он ничего не пересоздаёт. Только осознанно запускайте загрузчик З07, потому что он **удаляет и пересоздаёт `retail_pz7`**.
