# Проверка З12

Запустить из `E:\OLAP` команду `py -3.11 pz12/scripts/check_contour.py`.

Скрипт проверяет raw, DuckDB, ClickHouse (MergeTree, count, SUM(amount), дубли) и дневную сводку, а результат записывает в `pz12/checks/results.md`. Пишет отчёт только в папку З12, данные CH и DuckDB не изменяет.

**Важно:** результат `PASS` из скрипта не заменяет UI-проверку Metabase и факт сдачи на чистом стенде. Отдельно откройте четыре карточки, проверьте фильтр и итоги З11.
