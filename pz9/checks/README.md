# Z09 — логи проверок

`results.md` создаётся автоматически после успешного запуска:

```powershell
py -3.11 pz9/scripts/build_aggregate.py
```

Запустить дважды. Каждый запуск добавляет запись; результат сравнивает количество детальных строк, сумму выручки по всей таблице, выручку января 2024 и ВСЕ группы день×магазин.
