# Проверки З05

После двух успешных запусков `py -3.11 pz5/etl/load.py` здесь автоматически появится `run_log.md` с двумя блоками `Успешный запуск`, количеством строк и суммой `SUM(amount)` до/после.

Тест на плохие данные: `py -3.11 pz5/etl/test_bad_data.py` — результат `PASS` означает, что `qty = -1` блокирует загрузку.

Не заменяйте реальный журнал ожидаемыми значениями из инструкции: для сдачи нужен вывод, полученный на вашем компьютере.
